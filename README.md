# Student Manager Spring Boot

A Student Registration System developed using Spring Boot, Thymeleaf, Spring Data JPA, and H2 Database.

## How to Run

1. Open the project in an IDE such as IntelliJ IDEA or Eclipse.
2. Run `StudentManagerApplication.java`.
3. Open the following URL in a web browser:

`http://localhost:8080/students`

## Features

- Add students
- View students
- Edit students
- Delete students
- Form validation
- H2 database
- Thymeleaf web interface
